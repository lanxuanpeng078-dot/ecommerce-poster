# 构图标签与参考角色

构图标签描述画面机制，一图可选多个。参考角色描述借鉴范围，每张代表图标一个主要角色；它与案例用途、归档版位分别独立。

## 统一标签

| 标签 | 定义与区别 |
| --- | --- |
| 中心英雄 | 一件或一组商品形成主要焦点；不要求严格居中。 |
| 左右分栏 | 图像与文字，或两组商品、角度、证据各占左右区域；包含原“左右并置”。 |
| 局部特写 | 放大部件、接口、纹理或佩戴位置，使细节成为主要证据；包含原“细节主导”。 |
| 完整与细节并置 | 同幅同时有完整商品识别锚点和局部证据；区别于只有局部特写。 |
| 字体主导 | 标题或活动数字是第一视觉焦点。 |
| 场景叙事 | 环境与动作共同解释使用情境或传播主题。 |
| 人物互动 | 人或宠物与商品有使用、携带、接触或明确引导关系；区别于单纯人物展示。 |
| 人物展示 | 人物穿着、佩戴或出镜承担形象展示，没有强调操作或互动动作。 |
| IP互动 | 可识别的卡通或文化角色与商品、环境发生叙事关系；区别于真实人物。 |
| 多商品组合 | 多件商品同幅陈列；不表示它们实际成套出售。 |
| 非对称构图 | 不同区域视觉重量明显不等，形成偏侧或偏角布局。 |
| 上下分区 | 图像、标题、价格或解释区沿纵向划分成不同层。 |
| 底部信息带 | 底边独立条带集中放价格、规则、服务或平台信息；是可叠加的局部机制标签。 |
| 卡片矩阵 | 多个有明确边界的卡片按网格组织商品或证据。 |
| 参数卡片列 | 一列短参数、卖点或服务卡片纵向排列；区别于多列卡片矩阵。 |
| 留白构图 | 较大空区主动承担视线停顿或文字容纳，不只是背景颜色浅。 |
| 舞台陈列 | 台座、台阶或展示台承托商品并组织高低层次。 |
| 前后景分层 | 用遮挡、尺度和落点把商品、道具或环境分为前中后景。 |
| 框中框 | 画面内部另有建筑洞口、边框或展示框聚焦主体。 |
| 多角度并置 | 同款商品的不同朝向或状态同时出现；不等同于多件商品组合。 |
| 斜向动线 | 商品、零件或视线沿对角线组织；包含原“斜向阵列”。 |
| 俯视陈列 | 商品在平面上平铺，通过俯视组织完整轮廓、排列及纹理；包含原“平铺编排”。 |
| 结构展示 | 展示可辨部件、接口或操作状态，未把整套零件分离。 |
| 结构拆解 | 零件或模块按装配关系分离排列；须依据真实结构。 |
| 信息环绕 | 多个短标签或图标围绕主体，用位置或引线对应具体部位。 |
| 拼贴叙事 | 来自多个图像、人物或图形的碎片在同幅拼接，围绕主题形成叙事背景。 |
| 文化场景 | 材料、环境或符号提供文化语境；可与场景叙事同时使用，不代表文化授权。 |
| 剖面结构 | 用剖切视角展示房屋或物体内部空间及功能分区；区别于零件拆解。 |
| 结构叠影 | 同一部件以重叠的角度或状态表示开合变化；区别于分开的小图对照。 |
| 对称透视 | 两侧近似对称的主体围绕中央消失点组织纵深和视线。 |

## 近义名称映射

| 原名称 | 统一名称 |
| --- | --- |
| 左右并置 | 左右分栏 |
| 细节主导 | 局部特写 |
| 斜向阵列 | 斜向动线 |
| 平铺编排 | 俯视陈列 |

所有实际使用的标签均在上表定义。逐图表和网页只保留统一名称；网页搜索同时识别原名称，避免旧检索词漏选。

## 参考角色

| 参考角色 | 借鉴范围 |
| --- | --- |
| 整图布局参考 | 比较整体主次、标题组织、商品呈现及动线；不等于可直接照搬。 |
| 局部机制参考 | 只借鉴部件特写、结构拆解、信息引线或解释卡片。整图可能缺完整识别锚点，不默认套用为首图或专题。 |
| 使用关系参考 | 借鉴真实乘坐、佩戴、携带、操作与接触关系；不默认借用原价格、人物和背景。 |

例如 2-补构图192 的四张部件说明卡为“局部机制参考”。2-补构图191 的生活场景与整车对照主要为“使用关系参考”。按形状归档到某版位，不代表适合作为该版位的完整排版。非代表图角色为“待逐图确认”。

先确定用途和商品子类型，再选参考角色，最后比较构图标签。位置与占比只描述案例，不是新图的生成参数。
