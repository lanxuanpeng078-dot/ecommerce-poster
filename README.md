# Ecommerce Poster Skill (ver.3)

This repository root is the complete skill package. It includes the Chinese entry point (`SKILL.md` / `SKILL.zh-CN.md`), the English entry point (`SKILL.en.md`), `agents/`, `references/`, and `assets/`.

## Use

Use the repository root as the skill directory so all relative references resolve. Read `SKILL.md` for the Chinese workflow or `SKILL.en.md` for the English overview. Supporting stage references and source material remain primarily in Chinese.

The `assets/` directory contains the two visual reference libraries used by the workflow. The complete package is about 224 MB; the largest individual file is under 3 MB, so the assets are stored directly in Git rather than split into parts.

The package was checked for local Markdown links. Poster generation was not run as part of this repository update.
