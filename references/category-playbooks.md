# 七类商品主视觉 Playbook

原文自述根据42张公开电商案例整理，该历史集合未附原图和来源索引，尚未独立核验；本包另含用户维护的612张本地参考图，两者不是同一集合。只迁移机制，不复制品牌资产、人物、文案或具体构图。

## 1. 快消食品

- **购买动机**：口味、份量、即时满足、性价比、送礼。
- **主体**：包装与可食状态并列；食品切面、拉丝、酥脆或配料承担食欲证据。
- **背景**：暖色、餐桌或干净浅底；避免让装饰抢过食品。
- **信息**：口味/规格/份量优先，促销价格可较强；卖点 1-3 个。
- **风险**：食品颜色失真、份量误导、原料或健康功效无证据。

## 2. 美妆护理

- **购买动机**：功效、成分、肤感、信任、礼赠与高级感。
- **主体**：单品或套装保持包装文字可读；质感光线和材质细节优先。
- **背景**：低信息留白、品牌色渐变、成分或科技隐喻。
- **信息**：主功效与证据优先；价格区克制或按活动加强。
- **风险**：夸大功效、伪造临床/排名、未经授权代言、模型误改包装字。

## 3. 3C 数码

- **购买动机**：性能、兼容、续航、结构、价格与换新。
- **主体**：产品英雄图；必要时展示开合、组件或多角度，但数量必须真实。
- **背景**：浅灰/冷色渐变、科技光带或促销几何；参数标签需整齐。
- **信息**：型号、核心参数、到手价优先；高密度版也要保留商品轮廓。
- **风险**：端口、按键、屏幕、配件和型号被生成错误；参数无来源。

## 4. 家居生活

- **购买动机**：功能解决、空间适配、容量、效率、易用与清洁。
- **主体**：商品完整可辨；场景提供尺度和使用方式，不能遮挡结构。
- **背景**：家庭空间、台面或简洁功能演示；大件商品需呈现比例。
- **信息**：商品价格图可突出容量/功率/尺寸/功能并集中促销信息；商品专题海报围绕一个主题组织场景与核心利益，必要参数和活动为辅助。
- **风险**：空间比例错误、功能演示不可能、认证和能效信息无证据。

## 5. 医疗健康

- **购买动机**：准确、可靠、易用、适用人群、售后与合规。
- **主体**：设备完整、显示界面和附件真实；人物只用于正确使用示范。
- **背景**：高对比但克制的蓝白、浅色或专业场景。
- **信息**：可验证参数、使用方式、保障和价格；避免密集恐吓式表达。
- **风险**：疗效承诺、绝对准确、医用/认证/补贴信息无证据，错误佩戴或操作。

## 6. 服饰鞋包

- **购买动机**：版型、材质、搭配、舒适、功能和人群风格。
- **主体**：商品轮廓与材质优先；模特场景、单品英雄图或多角度按目标选择。
- **背景**：生活方式、运动速度感或高留白品牌空间。
- **信息**：版型/材质/功能点 1-3 个；促销信息不遮挡轮廓。
- **风险**：颜色、纹理、Logo、鞋底结构和人体比例失真；肖像授权不明。

## 7. 其他类别

先执行主流程阶段 2 的分类路径确认：手动指定类目 / 同意通用策略 / 补充资料重新分类。记录确认，不能跳过；不将某个相邻类目的专用策略整套套用。用户同意通用策略后，按已证实的商品属性确定购买动机，选择商品证据、使用场景或商业利益组织视觉，使用真实素材，保留待核实项；以下是启发，不是所有其他商品的统一模板。

- **分类方法**：先识别购买动机，再映射到“商品证据 / 场景体验 / 促销利益”。
- **户外用品**：场景证明空间、耐候或便携，但商品仍需独立可辨。
- **宠物食品**：包装保真 + 宠物/原料场景 + 配方证据；不得暗示治疗。
- **礼盒与特殊包装**：包装结构和内容物数量优先，场景只支持用途。
- **风险**：用通用品类模板掩盖关键决策线索；无法说明为什么适合该品类。

## 跨类决策

当商品跨类时，选择主要购买动机对应的 Playbook，最多借用一个相邻类目的机制。分类锚点见主流程阶段 2。涉及健康动机可借用证据与表达约束，但不能由此推断商品具有医疗属性。
