# 电商海报ver.3 阶段规则

本文件沿用ver.2阶段基础；信息规划以本版本SKILL.md和series-information-priority.md为准，模型调度见model-routing.md。文内 references/、assets/ 路径相对技能根目录解析。

## 阶段 1：解析输入与识别版位

在分类、提出方向和生成图片之前，先明确要求用户提供以下六类输入。已有资料先填入，仅收集缺项；不得只凭商品图直接开始完整海报设计。

1. **商品图**：清晰主视图，可补充侧面、背面、细节图；确认是同一商品的不同角度还是多个商品/套装。
2. **商品参数**：名称、品牌/型号、规格、尺寸、材质及相关性能参数。未知填“未知”，不从外观推断性能。
3. **卖点**：先收集完整卖点与证据，再区分核心利益和功能组；每页通常一个主卖点、最多两个辅助组，系列总信息不受三条限制。
4. **价格**：金额、币种、价格类型（售价/活动价/券后价等）；不展示时明确填“不展示”。
5. **活动规则**：活动内容、起止时间、参与门槛、优惠计算方式、赠品条件及必放说明；没有活动明确填“无活动”。
6. **画布规格**：用途/平台/版位、宽×高及单位、横竖方向、输出格式；印刷另需分辨率与出血。规格未定时先提出建议供用户确认，不将商品图比例当作画布规格。

补充项：品牌 Logo/配色/字体、目标人群、风格参考、必放文案、交付数量、截止时间。

用一份可填写清单集中收集六项，不受“最多 3 个追问”的数量限制。每项标明已收到/缺失/待确认/不适用；空白不等于“无活动”或“不展示价格”。缺少关键输入时保持“信息不足”，先等待补充。只有用户明确要求先试稿时，才可以声明假设后制作草案，且未知价格、活动、参数不得进入画面。仅评价现有海报等单阶段任务，只收集该阶段必要输入。


按需求表归一化商品、受众、卖点证据、商业信息、品牌资产、平台、版位、尺寸和交付数量。将输入标为 `已确认 / 合理假设 / 缺失 / 冲突`。

先判断输出类型：

- **商品首页图/搜索首图**：商品与购买利益优先；进行小尺寸测试。
- **活动主图**：活动机制、价格和时间优先；保留规则区。
- **品牌 KV/详情页头图**：品牌情绪与核心利益优先；允许更多留白。
- **横幅/社交广告**：按裁切、安全区和行动入口调整构图。

完成输入清单后，单轮集中追问不超过 3 项会显著改变结果的缺失项，不碎片化逐条追问。这是单轮上限，不是整个任务的总次数上限；仍缺核心信息时维持“信息不足”，等待用户批量补充，不编造参数、价格或卖点。不得虚构价格、参数、功效、认证、活动规则或品牌资产。

### 非首图版位的价格展示确认（生成前必问）

商品首图以外的每个版位（包括商品专题海报、详情页头图／横幅、品牌KV等），必须在构思和生成A/B/C预览前，分别询问并记录“是否在该版位展示价格”。不能将用户提供价格、选择多个版位、存在促销活动或首图展示价格视为其他版位也展示价格的确认。

- 多版位可一次集中询问，例如“专题海报、横幅各自是否展示价格？”，但必须逐版位记录答案。
- 用户本次已明确某版位展示／不展示价格时直接沿用，不重复询问；未确认时该版位保持信息不足，不生成含价格的预览，也不自行决定省略后开始生成。
- 确认展示后按已确认价格类型排版，并保留券后说明等必放规则；确认不展示时，不放售价、活动价、券后价、删除线对比价或优惠金额。活动名称与日期是否展示仍按用户活动要求处理。
- 首图仍按原价格输入流程，支持用户明确“不展示”；本规则不自动移除已确认和已选预览中的价格。
### 推荐比例与像素尺寸（确认版位时必列）

用户尚未指定规格时，必须主动同时列出宽:高比例、对应宽×高像素和横竖方向供选择，不能只问尺寸或只给比例。以下为设计建议，不声称平台官方规定；有明确平台要求或用户规格时优先采用，不重复询问。

|版位|推荐比例（宽:高）|对应像素尺寸|方向|
|---|---|---|---|
|商品首图|1:1|1024×1024 px|方形|
|商品专题海报（优先建议）|3:4|1536×2048 px|竖版|
|商品专题海报（备选）|4:5|1600×2000 px|竖版|
|商品专题海报（备选）|2:3|1600×2400 px|竖版|
|商品专题海报（长竖版）|9:16|1080×1920 px|竖版|
|详情页头图／横幅（优先建议）|16:9|1536×864 px|横版|
|详情页头图／横幅（备选）|2:1|1920×960 px|横版|
|详情页头图／横幅（宽横版）|3:1|1920×640 px|横版|

展示建议后等待用户确认，再生成；已有本次有效规格直接沿用。新商品或新用途不得自动继承旧任务规格。两种及以上版位必须分别独立创作，仍各自确认比例与像素。预览工具实际尺寸可能不同，须标注实际尺寸；最终导出核验目标尺寸，放大不代表新增真实细节。印刷另行确认物理尺寸、分辨率和出血。

### 商品专题海报的尺寸确认

商品专题海报开始构思或生成前，检查用户是否已明确给出本次海报的尺寸或宽高比例。未提供时，先确认尺寸或比例及横竖方向，再生成预览；用户已提供的有效规格直接沿用，不重复追问。

从商品首图、广告图等切换到商品专题海报时，旧版位的尺寸不自动视为新海报规格；若用户未明确沿用，先确认。参考案例的比例、商品原图比例也不能替代用户选择。

比例统一按“宽:高”解释；比例与横竖描述冲突时（如“16:9竖版”），先确认是9:16竖版还是16:9横版，不静默交换或按假设出图。用户只给比例时可据此制作预览，导出时注明实际像素尺寸；如有具体平台或印刷尺寸要求，再补齐必要规格。

### 多版位工作模式

- **强制独立创作**：用户选择两个及以上版位时，各版位必须独立创作，禁止统一设计后仅适配尺寸；不再询问系列适配或独立创作。
- **独立创作**：每种版位分别确定传播任务、参考、主体呈现、信息组织与视觉动线，不直接复用同一套提示词只改尺寸。
- 单一版位仍按该版位生成A/B/C；同一版位的尺寸导出不视为新增版位。两个及以上版位分别确定传播重点、参考、构图和信息层级；可保持品牌一致，但不得共用一套设计进行横竖适配。
- 构思前记录版位差异表：版位/目标尺寸、主传播任务、必放与可省略信息、参考编号及角色、主体呈现、信息组织、视觉动线、需要的商品素材。统一商品事实不代表每种版位必须展示全部相同文字。
- 独立创作每个版位分别生成A/B/C三张代表页真实预览；三个版位为9张方向预览，不等于9张最终系列页。各版位内同一代表页保持相同已确认事实与比例。允许同一叙事方向按版位发展不同构图。用户可分别选择，未选择的版位继续等待，不默认套用已选方向。

### ver.3 固定项与张数
明确区分版位数量、方向预览数量、系列最终张数和语言版本。“只要横幅”不限制张数；固定数量不得自行改变。阶段3前读取series-information-priority.md，记录固定项、信息完整清单、拟定系列页数及原因，不用同一版位重复追问已确认尺寸与价格开关。
