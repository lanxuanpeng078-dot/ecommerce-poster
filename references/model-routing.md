# 模型类别与阶段分工

日期：2026-10-11；候选调度建议，尚未做模型对比或费用测量。

“较低版本”在这里拆为低成本档与旧代模型。旧不一定更省、也不一定更适合。优先按任务能力选择经济档，只有环境实际提供且工具/视觉能力够用时才用旧代备选。

## 类别标注

|标记|类别|本环境模型举例|建议推理强度|适用边界|
|---|---|---|---|---|
|D|确定性工具，无需新增模型请求|rg、文件API、表格筛选、图像元数据读取、算术与导出脚本|不适用|固定规则、数字、路径、命名、尺寸；工具调用仍可能有宿主上下文开销|
|L|低成本轻量文字/视觉模型|GPT-6 Luna；旧代备选GPT-5.6 Luna|low，必要时medium|边界清楚的提取、模板填充、候选粗筛、摘要与简单检查|
|M|主力推理与多模态模型|GPT-6.1 Sol；环境只提供GPT-6 Sol时可作为替代候选|medium；有冲突时high|策略、创意、构图、提示词决策、图文验收|
|H|旗舰复杂推理与多模态模型|GPT-6 Astra|medium/high；不默认xhigh/max|疑难品类、复杂证据、跨版位重复、严重保真/透视缺陷诊断|
|I|专用图像生成/编辑模型|当前可用imagegen工具；服务背后的型号未暴露则写“未暴露”|使用工具支持的参数|真实出图，不能用L/M/H文字模型替代，不假定工具能切换低档|

这是推荐起点，不能用未做的测试证明哪个模型足够。模型名与实际账号可用性需核对；本次没有启动任何低档模型或多代理请求，也没有更改用户默认模型。

|尺寸导出、复制、命名、压缩|D；脚本首次异常M|复杂合成脚本M/H|复用可靠脚本，不为每次导出重新写整套代码|
|评分、来源与交付整理|L|未过硬门槛需M判断|复用状态，长记录写文件，用户只看结果与风险|

较高档优先保留在三个关口：创意架构、生成前的相机/场景一致性、成图保真验收。旗舰只诊断难点，不默认包办所有阶段。没有研究依据时不填预估市场价格；也不要为这个非必要字段额外启动研究任务。

## 调度与升级规则

1. 能用确定性工具的内容不单独请求模型；L负责一个完整资料/整理阶段，而不是为每个字段创建一次调用。
2. L出现事实冲突、无法定位证据、视觉索引不一致时升级M，仅交接冲突字段与相关素材。
3. M发现创意无法满足差异门槛、真实商品结构不清、严重透视或保真问题时，H诊断一次，输出1–3项缺陷、证据位置、可执行动作及停止条件。
4. 问题是工具能力时，不继续提高文字模型或重复出图。选择符合工具权限的原图像素保护方式；做不到则如实保存制作稿。
5. 同阶段不频繁往返切模型；通过的事实和构图参数冻结，用户变更才回溯。
6. 宿主不能自动切模型时给出推荐档位，不能声称Skill已完成实际路由。账号的费用、额度、文本token、推理token、视觉输入和绘图调用分别记录。

## 最小交接包

项目ID与当前阶段/状态；已确认事实及来源；各版位比例、像素、价格开关；必要原图路径与尺寸；少量参考路径及角色；每稿概念、镜头/透视/占比/承托；选择记录；当前缺陷与证据；本阶段输出与停止条件。文件内容可写入state.json；下游只读必要字段。

不传整份Skill、不复制全聊天、不回传全部参考图片或每张完整长提示词；需要的规则由目标模型按阶段加载。完整记录仍保存在项目文件，不能因压缩交接而删除事实依据。

## 消耗口径与建议预算

模型降档主要影响单价与推理开销，不保证同文本更少token。减少token靠缩小输入、避免重复、限制无效返工；绘图调用是独立项。可以记录每次调用的模型/推理档、输入/缓存/输出/推理token、绘图数量、耗时、费用、重试原因；接口未暴露写“未知”，不能拿估计填真实日志。

内部建议：状态摘要控制在约800–1200中文字，L回复通常不超300字，M阶段结论通常不超600字；必要事实/硬缺陷可超出。参考候选初筛每版位3–5项，再实际开少量适用图。数字为运行预算建议，不是已验证最优值或强制删减事实。
