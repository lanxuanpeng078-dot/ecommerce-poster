# 产品分析与风格匹配模板

阶段 2 输出基础判定，阶段 3 补齐核心分析，阶段 4 为各方向填写建议风格，阶段 5 用户选择后记录已选风格。严格保留全部必填字段，不允许删减；未知信息填“待补充”，未验证填“待核实”，不适用说明原因。按阶段检查基础判定四项、核心分析四组（卖点三栏）、风格匹配三项（关键词五个），以及当前品类的全部附加字段；后续阶段字段暂填“待该阶段”。有占位不代表已具备制作条件。

## 一、基础判定

- 产品名称：
- 所属大类：[快消食品 / 美妆护理 / 3C数码 / 家居生活 / 医疗健康 / 服饰鞋包 / 其他]
- 置信度：[高 / 中 / 低]
- 边界备注：[若跨类，说明为什么归到这一类；否则填“无”]

同时保留子类型、分类依据与相邻类目。“3C数码”“其他”分别对应主流程的“3C 数码”“其他类别”。

## 二、核心分析

- 目标人群：[年龄 / 性别 / 场景]
- 核心卖点（3 条，每条不超过 15 字）：
  1. [主卖点]
  2. [辅助卖点]
  3. [辅助卖点]
- 价格带判断：[低端 / 中端 / 高端] + 预估区间 ¥XX–¥XX
- 使用场景：[早餐 / 送礼 / 通勤 / 熬夜 / 换季等]

目标人群的推断须注明；性别不限可填“不限”，不要根据颜色推定性别。卖点保留三个栏位，证据不足填“待补充”，不凑数；依据另列，不计入 15 字限制。每页仍以一个主焦点、少量辅助组组织；完整功能按series-information-priority.md整组分配，三栏分析不是输入或整组覆盖上限。

价格带依据同子类、同规格可比商品，记录依据、币种、单位；涉及当前行情需核验来源和日期。缺依据填“待判断，区间待核实”，不凭外观猜价。预估仅作设计定位，不是售价，不写入海报价格区。非人民币商品保留真实币种，不自动换算。

## 三、风格匹配

- 已选风格：[从风格库中选择]
- 视觉关键词（5 个）：
- 参考图锚点：[引用 assets 中对应风格的参考图编号 + 相对路径]

用户未选择时，已选风格填“待选择”，另列建议风格。引用前核查风格库与参考图文件，实际查看图片并说明借鉴点。无风格库填“风格库待建立”，可提供临时建议但不声称来自库；无参考图填“参考图缺失，待用户提供”，不编造编号。本包 assets 含七类商品的真实参考图；按商品类目与01/02/03用途目录选择，具体路径见 ../SKILL.md。icon.svg 仅为界面图标。用户增删素材后以实际文件为准，不假定固定图号。

## 品类附加字段

按主类目追加全部对应字段；缺失填“待补充”，确实不适用填“不适用”并说明，如有线产品无续航指标。跨类时按需补充相邻品类字段。

| 大类 | 额外必加字段 |
|---|---|
| 快消食品 | 口味 / 规格 / 保质期 |
| 美妆护理 | 肤质 / 成分 / 是否敏感肌可用 |
| 3C 数码 | 接口 / 续航 / 兼容系统 |
| 家居生活 | 材质 / 适用空间 / 尺寸 |
| 医疗健康 | 适用人群 / 禁忌 / 是否需医嘱 |
| 服饰鞋包 | 尺码 / 版型 / 季节 |
| 其他 | 补充说明 |

成分、保质期、敏感肌适用性、禁忌和医嘱要求等须依据包装、说明书或可核验资料。无依据填“待核实”，不作适用性或安全性保证。
