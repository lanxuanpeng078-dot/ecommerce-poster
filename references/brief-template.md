# 电商主视觉需求表

## 开始设计前请用户填写

先填写用户已提供的信息，只请补充缺项。必须显式收集以下六项：

- 商品图：请上传或提供文件位置；说明多张图对应不同角度还是不同商品。
- 商品参数：名称、品牌/型号、规格、尺寸、材质、相关性能；未知项注明。
- 卖点：完整卖点及证据清单、核心利益与功能分组；每页一个主卖点和少量辅助组，不限制整组信息只有三条。
- 价格：金额、币种、售价/活动价/券后价；或填“不展示”。首图之外的版位必须逐一提前询问是否展示价格；已提供价格不等于同意所有版位展示。
- 活动规则：活动内容、起止时间、门槛、优惠算法、赠品条件、必放说明；或填“无活动”。
- 画布规格：用途/平台/版位、宽×高（px 或 mm）、横竖方向、输出格式；印刷补充分辨率/出血。不确定可填“请建议”，由助手提出后待用户确认。
- 其他要求（选填）：目标人群、品牌资产、参考风格、必放文字、数量与截止时间。

## 按品类追加参数

基础资料足以分类后，按 `product-analysis-template.md` 中“品类附加字段”表追加该类全部字段到需求表。资料不足不强行分类；待分类后补齐。每项记录值及来源，未知填待补充，不适用须说明。该模板同时规定基础判定、核心分析和风格匹配的输出格式。

## 素材记录

记录文件名、尺寸、授权状态、用途和优先级：商品正面/侧面/细节图、包装展开图、Logo、字体、人物或场景图、图标、活动规则、参考案例。

## 京东式商品首页图附加项

- 缩略图必须保留：商品 / 主卖点 / 价格或活动中的哪些信息？
- 商品目标占比：大 / 中 / 小；是否允许多 SKU、赠品或场景人物？
- 信息密度：低 / 中 / 高；卖点标签上限。
- 背景类型：纯底 / 渐变 / 功能场景 / 生活场景 / 促销几何。
- 平台遮挡与角标位置：已确认 / 待核实。

## 缺口处理

先收集六项输入，不受追问数量限制；清单完成后单轮集中追问不超过 3 项关键缺失信息，不是全任务最多三次；仍缺关键信息时保持信息不足，等待批量补充。缺少关键输入时等待补充，不自行跳过。用户明确要求先试稿时才按已声明假设做草案；不编造价格、参数或活动，空白不等于无活动。单阶段评价仅收集必要资料。

## 商品专题海报附加项

- 确认用途为专题海报，并记录主题、核心利益、场景和所选02类参考路径。
- 未给尺寸或宽高比例时先确认；不从上一版位或参考图自动继承尺寸。比例统一为宽:高，横竖描述有冲突先澄清。
- 生成前必须先询问专题海报是否展示价格；明确确认后再决定价格与活动的信息层级，不从首图或已提供金额推断。

## 多版位需求
- 版位数量：记录已选择版位；两个及以上版位强制分别独立创作，禁止统一设计适配，不询问创作模式。单一版位按该版位构思。
- 每个版位分别记录：目标尺寸、传播任务、价格是否展示（非首图必须先问）、必放/可省略信息、参考编号与角色、主体呈现、信息组织、视觉动线、所需素材。
- 独立创作各版位各生成A/B/C，分别等待选择；不将一个版位的选择自动扩展到其他版位。


规格未定时，必须同时展示SKILL.md的推荐比例、对应像素尺寸与方向供用户选择；不能只询问尺寸或只列比例。用户确认后生成，本次已提供有效规格则不重复询问。
