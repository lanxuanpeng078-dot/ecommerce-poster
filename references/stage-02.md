# 电商海报ver.3 阶段规则

本文件沿用ver.2阶段基础；信息规划以本版本SKILL.md和series-information-priority.md为准，模型调度见model-routing.md。文内 references/、assets/ 路径相对技能根目录解析。

## 阶段 2：产品类型分类

读取 `references/product-analysis-template.md`，严格保留全部必填字段，不删行；无内容填“待补充”，待验证填“待核实”，确不适用注明理由。按阶段逐步填写，进入下一阶段前核对当前阶段字段；占位完整不等于事实已核验。按“一、基础判定”输出产品名称、大类、置信度（高/中/低）和边界备注。分类后按该模板的品类表补充对应参数；已有信息不重复询问，缺项并入需求清单。

必须先分类，再制定视觉策略。输出 `主类目 + 子类型 + 决策理由 + 置信度 + 相邻类目`。主类目只选一个：

1. 快消食品
2. 美妆护理
3. 3C 数码
4. 家居生活
5. 医疗健康
6. 服饰鞋包
7. 其他类别

分类依据依次为：消费者购买动机、核心证据、使用场景、商品形态、合规风险。跨类商品选择主要购买动机对应的类目，并记录次要类目。随后读取对应类目 Playbook；禁止对所有品类套用同一构图。


### 跨类判定与其他类别分支

以下是设计策略分类锚点，不是法规分类或医疗资质判断；先核对商品说明，再结合购买动机，不能仅凭名称或营销话术判定。
- 蛋白粉、膳食补充剂：普通食品用途可按快消食品组织；明确的营养健康定位可借用医疗健康中的证据约束，但不因此认定具有医疗属性或疗效。性质不清时降低置信度并要求补充资料。
- 香薰、无火香氛：家居装饰或空间香氛归家居生活；身体护理用途归美妆护理，使用方式不明则待确认。
- 智能手环：普通运动记录、提醒与消费电子功能优先归 3C 数码；健康相关数据本身不足以认定医疗属性。医疗用途须核验说明与相应资料，再选择设计策略。
跨类必须在边界备注说明依据和次要类目；低置信度、用途冲突且影响方案时，回到信息不足，不武断选类。

主类目为“其他类别”时：
1. 说明为何不适合预设六类，列出两个最接近的相邻类目及借鉴点；确无合理相邻项时说明原因，不为凑数错配。
2. 不强行套用六类专用 Playbook；通用策略见 references/category-playbooks.md 的“其他类别”。
3. 设为“待人工选择（分类路径）”，提供：①手动指定类目 ②使用通用电商设计策略 ③补充资料重新分类。确认后才进入阶段 3；已有明确授权沿用并记录。
4. 选择①核对分类依据后继续，有事实冲突先澄清；选择②使用通用策略；选择③回到信息不足。分类路径确认不代替阶段 5 的设计方向选择。
